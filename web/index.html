검색 및 판별 설정

질의 키워드가 뭉쳐 있는 구절을 끌어올립니다.

신뢰도는 지지 / 미지 지지 분할의 정규화 엔트로피를 1에서 뺀 값입니다. 이 모델의 확률값은 압축되어 있어 유용한 기준선은 낮은 편(0.05–0.3)입니다. 기준선 미만이면 판정이 보류되어 사람의 검토를 기다립니다. 두 슬라이더는 모델 호출 없이 현재 결과를 즉시 재분류합니다.

      동작 방식
      
      
      모든 문서는 짧은 구절로 나뉘어 다국어 MiniLM으로 임베딩되며, 벡터는 이 브라우저의 IndexedDB에 저장됩니다. 주장도 같은 방식으로 임베딩되고, 기본 검색기는 브루트포스 코사인 스캔입니다. 하이브리드로 바꾸면 같은 스캔에 한국어 대응 BM25 키워드 점수를 융합하고(가중치 슬라이더), 근접성 리랭킹은 질의 키워드가 뭉쳐 있는 구절을 끌어올립니다(advancedRagDemo에서 가져온 2단계 리랭커). 주장과 이 구절들이 Laya 의사결정 모델의 유형화된 질문의 상태(state)가 되고, 모델은 생성 텍스트 대신 각 선택지의 확률을 반환합니다. 이 확률이 판정을 결정하고, 그 신뢰도가 판정을 자동으로 실행할지 사람에게 보류할지 결정합니다. 모든 과정이 이 탭 안에서 실행됩니다: 서버도, API 키도 없습니다.
      
      
      평가 페이지에서는 같은 파이프라인을 예시 주장 72개 전체에 실행하고 골드 라벨과 비교해 점수를 매깁니다.
